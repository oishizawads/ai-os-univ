# 避ける構造パターン（言語非依存）

> 出典: wpgaurav/claude-code-skills (MIT)。これらは日本語・英語どちらにも効く。

## 二項対立の煽り（Binary Contrasts）
偽のドラマを作る。直接言え。
| パターン | 問題 |
|---|---|
| 「Xではない。Yだ」 | テンプレ的な反転 |
| 「Xは問題じゃない。Yが問題だ」 | 定型リフレーム |
| 「答えはXではない。Yだ」 | 予測可能なピボット |
| 「Xに見える。実はYだ」 | setup/reveal の陳腐化 |
→ 代わりに: Yを直接述べる。「問題はYだ」

## ドラマ化した断片（Dramatic Fragmentation）
強調のための体言止め・短文連打は「作られた深み」に見える。
| パターン | 問題 |
|---|---|
| 「Xだ。それだけ。それが全て」 | わざとらしい簡潔さ |
| 「Xも。Yも。Zも。」 | スタッカートのドラマ |
→ 代わりに: 完全な文。提示より内容を信頼。

## 修辞的セットアップ（Rhetorical Setups）
洞察を「告知」して「提供」しない。
| パターン | 問題 |
|---|---|
| 「もし〜だとしたら？」 | ソクラテス気取り |
| 「つまりこういうことだ：」 | 冗長な予告 |
| 「考えてみてほしい：」 | 上から目線 |
→ 代わりに: 要点を言う。結論は読者に委ねる。

## 偽の網羅（False Ranges）
| パターン | 問題 |
|---|---|
| 「XからYまで、AからBまで」 | range積み重ね＝水増し |
| 「Xであれ、Yであれ」 | 偽の網羅性 |
→ 代わりに: 一番効く具体例を1つ。

## 類義語サイクリング（Elegant Variation）
同じ語の繰り返しを避けて類義語を循環させると、辞書ドリブンに見える。
| パターン | 問題 |
|---|---|
| ツール→基盤→ソリューション→製品 | 同じものを4つの名前で |
| 重要→不可欠→必須→肝要 | エスカレートする類義語 |
| 使う→活用→レバレッジ→運用 | 無意味な凝り |
→ 代わりに: 自然な語を繰り返す。「ツール」を3回の方が読みやすい。

## 一般的ポジティブな締め（Generic Positive Conclusions）
内容に関係なく楽観的・前向きな結びに逃げる。
| パターン | 問題 |
|---|---|
| 「今後が楽しみだ」「明るい未来が」 | 根拠のない楽観 |
| 「時間が解決するだろう」 | 非コミットな埋め草 |
| 「一つ確かなことは：」 | わざとらしい確信 |
→ 代わりに: 具体的なアクション・推奨・正直な評価で締める。

## リズムパターン
| パターン | 修正 |
|---|---|
| 3項目リスト | 2項目か1項目に |
| 問いに即答 | 問いを呼吸させるか削る |
| 毎段落キメ台詞で終わる | 結びを変える |
| 暴露前の em-dash（—） | ピリオド/カンマに |

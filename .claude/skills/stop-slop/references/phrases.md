# 削除・置換するフレーズ（日英）

> 出典: wpgaurav/claude-code-skills (MIT) を日本語クライアント文書向けに拡張。
> 機械的に消さず、文意が通るか確認してから適用する。

## 日本語：前置き・枕（消す）
- 「〜について考えてみましょう」「〜について見ていきます」
- 「結論から言うと」（と言いながら結論が遠い場合）
- 「ここで重要なのは」「言うまでもなく」
- 「ご存知の通り」「改めて言うまでもありませんが」
- 「まず大前提として」（本当に前提でないとき）

## 日本語：重要性インフレ（具体に置換 or 削除）
- 「極めて重要」「非常に重要」→ なぜ重要かを書くか削る
- 「画期的」「革新的」「次のレベル」「圧倒的」→ 具体的な差分に
- 「〜と言えるでしょう」「〜と考えられます」→ 断定できるなら断定、できないなら根拠を
- 「様々な」「多くの」「各種」→ 数や具体名に
- 「効果的に」「シームレスに」「最適化された」→ 何がどう良いか

## 日本語：冗長・つなぎ（削る）
- 「〜という形で」「〜といった形」
- 「〜することが可能です」→「〜できます」
- 「〜を行う」→「〜する」
- 「〜に関して」「〜について言うと」
- 「基本的に」「ある意味」「ある種の」

## 英語：Throat-Clearing Openers（消す）
- "Here's the thing:" / "The uncomfortable truth is" / "It turns out"
- "Let me be clear" / "The truth is," / "I'm going to be honest"

## 英語：Emphasis Crutches（削除）
- "Full stop." / "Period." / "Let that sink in." / "Make no mistake"
- "This matters because" / "Here's why that matters"

## 英語：Business Jargon（言い換え）
| Avoid | Use |
|---|---|
| Navigate (challenges) | Handle, address |
| Unpack / Deep dive | Explain, examine |
| Lean into | Accept, embrace |
| Game-changer | Significant |
| Double down | Commit, increase |
| Moving forward | Next, from now |
| Circle back | Return to |
| On the same page | Aligned |

## 英語：Filler（削除）
- "At its core" / "In today's [X]" / "It's worth noting" / "Interestingly,"
- "Importantly," / "At the end of the day" / "When it comes to" / "In a world where"

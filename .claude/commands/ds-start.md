# ds-start

## Objective
Initialize a data science task with clear objective, validation, risks, and execution path.

## Output Format
- Objective
- Scope
- Data or project context
- Validation plan
- Leakage or bias risks
- Baseline or starting point
- Recommended execution route
  - direct coding
  - experiment workflow
  - decision-lab
- Next actions

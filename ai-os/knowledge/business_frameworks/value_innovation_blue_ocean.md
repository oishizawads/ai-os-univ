# ブルー・オーシャン戦略 — 市場創造フレームワーク

> 出典: W・チャン・キム、レネ・モボルニュ『ブルー・オーシャン戦略』
> 用途: 競合のない市場の創造、差別化と低コストの同時追求（バリュー・イノベーション）

---

## 0. 根本原則

```
血みどろの戦い（レッド・オーシャン）を避け、未知の市場空間（ブルー・オーシャン）を切り拓く。
```

- **バリュー・イノベーション**: 買い手への価値を飛躍的に高めると同時に、自社のコストを下げる。
- **非顧客への注目**: 既存顧客だけでなく、業界を敬遠している「非顧客」のニーズに応える。

---

## 1. 分析ツール: 戦略キャンバス

既存業界の標準的な「競争要因」を横軸に、その充実度を縦軸にプロットし、自社の「価値曲線」を描く。
- **目的**: 競合と同じ土俵で戦わず、独自の価値曲線を描くこと。

---

## 2. 実行ツール: 4つのアクション (ERRC)

独自の価値曲線を作るために、以下の4つの問いを立てる。

| アクション | 問い | 目的 |
|-----------|------|------|
| **取り除く (Eliminate)** | 業界の常識とされている要素で、取り除けるものは何か？ | コスト削減・複雑さの排除 |
| **減らす (Reduce)** | 業界標準よりも大胆に減らすべき要素は何か？ | 過剰サービスの是正 |
| **増やす (Raise)** | 業界標準よりも大胆に増やすべき要素は何か？ | 顧客満足度の向上 |
| **付け加える (Create)** | 業界がこれまで提供したことのない要素で、新しく付け加えるべきものは何か？ | 新規価値の創造 |

---

## 3. 6つのパス（市場境界を引き直す）

1. **代替産業に学ぶ**: 違う業界の製品が、なぜ同じニーズを満たしているか？
2. **業界内の他の戦略グループに学ぶ**: 高級志向 vs 低価格志向の間にある隙間は？
3. **買い手グループを再定義する**: 意思決定者ではなく、利用者に直接訴求できないか？
4. **補完財やサービスを見渡す**: 製品を使う「前・中・後」に何が起きているか？
5. **機能志向・感性志向を切り替える**: 感情的な業界を機能的に、機能的な業界を感情的にできないか？
6. **将来を見通す**: 今起きているトレンドが、将来どう市場を変えるか？

---

## 4. チェックリスト

### 企画・戦略策定の際に

```
[ ] 競合の真似（ベンチマーク）に終始していないか？
[ ] ERRCのうち、特に「取り除く」「付け加える」を大胆に行っているか？
[ ] その戦略は、コストダウンと価値向上の両立を実現しているか？
[ ] ターゲットは、既存顧客の奪い合いではなく「非顧客」を含んでいるか？
[ ] 独自の価値曲線は、一言で表せるほど明快（焦点が絞られている）か？
```

## Claude に適用する場合のプロンプト冒頭

```
ブルー・オーシャン戦略の視点で、独創的な戦略を提案してください。
1. 現在の「レッド・オーシャン（既存競合）」の競争要因を特定する
2. ERRCフレームワーク（取り除く・減らす・増やす・付け加える）を用いて、独自の価値曲線を設計する
3. 特に、業界が「当たり前」だと思っている要素を「取り除く」ことで、どのようにコストと価値を最適化できるか示す
4. これまでその製品・サービスを利用していなかった「非顧客」を惹きつけるための鍵を特定する
---
[本題をここに記述]
```

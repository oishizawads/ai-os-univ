# メンタル・マネジメント (Search Inside Yourself) — 心のOSフレームワーク

> 出典: チャディー・メン・タン『サーチ・インサイド・ユアセルフ（SIY）』
> 用途: 感情的知性 (EQ) の向上、レジリエンス（回復力）の強化、集中力の維持

---

## 0. 根本原則

```
マインドフルネス = 意図的に、今この瞬間に、批判せずに注意を払うこと。
```

- **心の筋力**: 自分の感情や注意の状態を客観的に観察し、セルフコントロールの基礎を作る。
- **EQ (Emotional Intelligence)**: 自己認識、自己調整、動機付け、共感、社会的スキルの5要素を鍛える。

---

## 1. 3つの核心的アプローチ

### 1. 注意力を鍛える (Attention Training)
「呼吸」などのアンカーに注意を戻す練習を通じ、心の静寂と集中力を養う。
- **効果**: 刺激に対する反応（感情の爆発など）に「スペース」を作れるようになる。

### 2. 自己認識を高める (Self-Knowledge)
自分の感情が、体にどのような物理的感覚（心拍、呼吸の変化など）として現れるかを観察する。
- **効果**: 感情に飲み込まれる前に「あ、今自分は怒っているな」と客観視できる。

### 3. 有益な心の習慣を築く (Mental Habits)
他者に対して「この人が幸せでありますように」と願う（慈悲の心）習慣を持つ。
- **効果**: 社会的なストレスを軽減し、協力的な人間関係を自然に築ける。

---

## 2. 感情を扱うテクニック: SBNRR

強い感情やストレスに襲われた際に、以下のステップで対応する。

1. **停止 (Stop)**: すぐに反応せず、立ち止まる。
2. **呼吸 (Breathe)**: 深呼吸して、今この瞬間に戻る。
3. **観察 (Notice)**: 体の感覚（胸の苦しさなど）を批判せずに観察する。
4. **再評価 (Reflect)**: 「これは自分の問題か？」「相手にも事情があるか？」と客観的に考える。
5. **対応 (Respond)**: 最善の行動を選択して実行する。

---

## 3. 実践のコツ

- **「ただ座る」だけではない**: 誰かの話を聴く時（マインドフル・リスニング）や、歩いている時（マインドフル・ウォーキング）など、日常のあらゆる瞬間に適用できる。
- **セルフ・コンパッション**: 自分を厳しく責めるのではなく、親友に接するように自分に接する。

---

## 4. チェックリスト

### 集中力が切れた、または感情が揺れたとき

```
[ ] 今、この瞬間に自分の注意はどこにあるか？
[ ] 今感じている感情を、体のどの部分（喉、胸、お腹など）で感じているか？
[ ] 刺激に対して、即座に「自動反応」していないか？
[ ] 自分自身に対して、優しさ（セルフ・コンパッション）を忘れていないか？
[ ] 周囲の人に対し「この人が幸せでありますように」と一度でも願ったか？
```

---

## Claude に適用する場合のプロンプト冒頭

```
マインドフルネスとEQ（感情的知性）の視点で、私の状況を整理してください。
1. 現在のストレスや課題を「批判せずに」客観的に記述する
2. その状況が私の「自己認識（内面の状態）」や「集中力」にどう影響しているか分析する
3. SBNRR（停止・呼吸・観察・再評価・対応）の手順に従い、感情に飲み込まれない具体的な対応策を練る
4. 周囲の人々との関係において、共感と慈悲（相手の幸せを願う）の視点を取り入れたコミュニケーション案を提示する
---
[本題をここに記述]
```

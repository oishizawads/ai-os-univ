# ロジカルシンキング — 論理的思考・伝達フレームワーク

> 出典: 照屋華子・岡田恵子『ロジカル・シンキング』
> 用途: 論理的に考え・論理的に伝えるための基盤

---

## 0. 根本原則

```
論理的であるとは、「So what?」と「Why so?」に常に答えられる状態を維持することである。
```

- **論理的に考える**: 物事の構造を正確に把握し、問題の本質を見極める
- **論理的に伝える**: 相手が「So what?」「Why so?」と感じないよう、先回りして答える

---

## 1. 2つのキー問答

### So what?（だから何？）
事実・情報 → 主張・結論。「これらの事実から、何が言えるのか？」

### Why so?（なぜそう言えるの？）
主張・結論 → 根拠・事実。「その主張は何によって支えられているか？」

---

## 2. 論証の3要素（Toulminモデル）

| 要素 | 定義 | 例 |
|------|------|---|
| **主張（Claim）** | 最も伝えたいこと | 「この施策を今すぐ実施すべきだ」 |
| **根拠（Grounds）** | 主張を支える事実・データ | 「顧客流出率が月3%に達している」 |
| **論拠（Warrant）** | 根拠から主張へのつながり | 「流出率3%超は緊急対応の閾値を超えている」 |

**論拠が欠けると**: 「競合がAI機能を実装した → わが社もAI機能を実装すべきだ」→ なぜその行動が必要かのルールが欠けている

---

## 3. MECEとロジックツリー

### MECEとは
- **Mutually Exclusive（相互排他）**: 重複がない
- **Collectively Exhaustive（網羅的）**: 漏れがない

### ロジックツリーの3種類
- **Whyツリー**: 原因分析（「なぜ〇〇が起きているか」）
- **Howツリー**: 解決策（「どうすれば解決するか」）
- **Whatツリー**: 構造分解（「〇〇はどのような要素から成るか」）

---

## 4. チェックリスト

### 考えるとき

```
[ ] So what?（この情報から何が言えるか）を答えられるか
[ ] Why so?（その主張の根拠は何か）を答えられるか
[ ] 論拠（根拠と主張のつながりのルール）は明確か
[ ] ロジックツリーはMECEになっているか
```

### 伝えるとき

```
[ ] 主張・根拠・論拠の3点セットが揃っているか
[ ] 聞き手が「So what?」と言いたくなる瞬間はないか
[ ] 聞き手が「Why so?」と言いたくなる瞬間はないか
```

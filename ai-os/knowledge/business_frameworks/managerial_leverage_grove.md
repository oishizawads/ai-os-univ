# マネージャリアル・レバレッジ — マネジメントフレームワーク

> 出典: Andrew S. Grove『High Output Management』
> 用途: マネージャーの生産性向上、チームアウトプットの最大化

---

## 0. 根本原則

```
マネージャーの生産性 = 自分一人の活動ではなく、チーム全体の出力を増やすこと。
マネージャーの活動は「レバレッジ（てこの原理）」で測る。
```

- **生産性**: 1単位のインプット（時間・リソース）に対するアウトプット
- **レバレッジ**: マネージャーの1つの行動が、多くの人や長期的に影響を与える度合い
- **最高のレバレッジ活動**: 多くの人に影響し、長期間にわたって効果が続く活動

---

## 1. マネージャーの活動の3分類

| 分類 | レバレッジ | 例 |
|------|-----------|-----|
| **情報収集** | 低〜中 | 会議参加、メール確認、1on1 |
| **意思決定** | 高 | 方針決定、リソース配分、採用・昇進 |
| **ナッジング（後押し）** | 最も高い | ミッションの設定、価値観の浸透、人材育成 |

- **情報収集は素早く**: 情報の質と量を上げ、意思決定の質を上げるための投資
- **意思決定は共有で**: 一人で決めず、関係者を巻き込むことでコミットメントと精度を上げる
- **ナッジングは最も効く**: 組織の「 OS 」を変える活動。一度やれば長期間効果が続く

---

## 2. 1on1 ミーティングの設計

 Grove流1on1は「部下主導」の情報収集の場。

- **頻度**: 最低週1回、30分〜1時間
- **主導権**: 部下が議題を持ち、自分の仕事・問題・気づきを話す
- **マネージャーの役割**: 聞く、問う、状況の文脈を補う。指示を出すのではない
- **タブー**: マネージャーが議題を握り、プロジェクト進捗確認だけにする

### 定番の問いかけ

```
- 今週、何か困っていることはありますか？
- あなたの仕事の中で、最も面白い・つまらない部分は何ですか？
- もし1つだけ変えられるとしたら、何を変えますか？
- 私（マネージャー）がもっとやるべきこと・やめるべきことはありますか？
```

---

## 3. 業績管理: OKR との関係

- **Objectives**: 何を達成したいか（定性的・野心的）
- **Key Results**: 達成をどう計測するか（定量的・具体的手法）
- **評価**: 達成度だけでなく「目標の難易度と状況の変化」を考慮する
- **重要**: OKRは「脅し」ではなく「対話の素材」にする

---

## 4. チェックリスト

### マネージャーとして振り返る

```
[ ] 今週の活動の中で、レバレッジが最も高かったものは何か？
[ ] 情報収集に費やす時間が、意思決定の質を上げているか？
[ ] 1on1は「部下主導」で、私が話す時間が少なすぎないか？
[ ] 「ナッジング」（価値観・ミッションの浸透）に時間を割いているか？
[ ] 部下の「レバレッジ」を上げるために、何を手放せるか？
```

## Claude に適用する場合のプロンプト冒頭

```
High Output Managementの視点で、マネジメント課題を整理してください。
1. 私の活動を「情報収集・意思決定・ナッジング」に分類し、レバレッジの高い活動を特定する
2. 1on1の議題を「部下主導」にし、傾聴と問いかけを中心に設計する
3. チーム全体の生産性を上げるための「レバレッジポイント」を探す
4. 「自分でやる」ではなく「部下に委ねて育てる」判断基準を示す
---
[本題をここに記述]
```

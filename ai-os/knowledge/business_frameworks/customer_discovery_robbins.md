# カスタマー・ディスカバリー（マム・テスト）— 顧客インタビューフレームワーク

> 出典: Rob Fitzpatrick『The Mom Test』
> 用途: 顧客の本音を引き出すインタビュー設計、偽の肯定を排除する

---

## 0. 根本原則

```
人々は、あなたの気持ちを傷つけないために嘘をつく。
正しい「質問」を設計すれば、誰からでも本音が聞ける。
```

- **The Mom Test**: あなたの母親に聞いても、嘘をつかずに有用な情報が得られるような質問設計
- **事実を聞く**: 意見・予測・感情ではなく、「過去の行動・具体的な数値・既存の代替手段」を聞く
- **アイデアを語らない**: 自分のアイデアを顧客にプレゼンすると、相手は「いいね」と言う義務を感じる

---

## 1. 3つの禁則質問

| 禁則 | 悪い例 | 理由 |
|------|--------|------|
| **意見を聞く** | 「この機能は欲しいですか？」 | 相手は気まずくて「はい」と言う |
| **未来の約束を取る** | 「もし作ったら買いますか？」 | 口約束は実際の行動と無関係 |
| **自分のアイデアを売る** | 「〇〇というアプリを考えているのですが…」 | 相手は「いいね」と言うが、本音ではない |

---

## 2. 正しい質問の設計

### 聞くべき3つの観点

1. **文脈（Context）**: その人の生活・仕事の中で、その問題がどこに位置するか
   - 「この作業について、今どのように進めていますか？」

2. **過去の行動（Past Behavior）**: 実際に何をしたか（金を払ったか、時間を使ったか）
   - 「これまでに同様の問題を解決するために、何を試しましたか？」
   - 「それにはどれくらいの費用・時間がかかりましたか？」

3. **現在の代替手段（Current Alternatives）**: 今はどうやってそのニーズを満たしているか
   - 「今、〇〇をやるとき、どのツール・方法を使っていますか？」
   - 「その方法のどこが面倒ですか？」

### 定番の質問セット

```
- この作業について、今どのように進めていますか？
- 最後にその問題が起きたのはいつですか？
- それを解決するために、何を試しましたか？どれくらいお金をかけましたか？
- どの部分が最も時間を取られますか？
- もし魔法の杖でそれを解決できるとしたら、どのように変わりますか？
```

---

## 3. インタビュー後の評価基準

| 評価 | 兆候 |
|------|------|
| **有望** | 顧客が「自分の言葉で」問題を語る。具体的な過去の行動・支出がある。既存の代替手段に不満がある。 |
| **要注意** | 顧客が「いいね」と言うが、具体的な話が出ない。未来の約束だけで過去の行動がない。 |
| ** stop** | 顧客が「便利かも」と言うが、今の代替手段に満足している。問題の自覚が低い。 |

---

## 4. チェックリスト

### インタビュー設計の前に

```
[ ] 自分のアイデアや製品名を質問の中に入れていないか？
[ ] 「欲しいですか」「買いますか」といった未来志向の質問を排除したか？
[ ] 「どう思いますか」ではなく「どうしていますか」を聞く設計になっているか？
[ ] 相手の過去の行動・支出・苦労話を引き出す質問を含んでいるか？
[ ] インタビュー後に「具体的な事実」を3つ以上書き留められる設計になっているか？
```

---

## Claude に適用する場合のプロンプト冒頭

```
「The Mom Test」の原則で、顧客インタビューの設計・分析を行ってください。
1. 私のアイデアを語らず、相手の「過去の行動・現在の代替手段・具体的な不満」を聞く質問リストを作成する
2. 「欲しいですか」「買いますか」といった偽の肯定を生む質問を排除する
3. インタビュー後のメモから、相手の本音（「金を払っている」「時間を使っている」「不満がある」という事実）を抽出する
4. 「有望」「要注意」「stop」の3つに分類し、次の行動を提案する
---
[本題をここに記述]
```

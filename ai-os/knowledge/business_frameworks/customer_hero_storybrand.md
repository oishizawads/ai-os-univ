# ストーリーブランド — メッセージ構築フレームワーク

> 出典: ドナルド・ミラー『ストーリーブランド戦略』
> 用途: プレゼン、ライティング、製品紹介、コミュニケーションの明快化

---

## 0. 根本原則

```
顧客はあなたの物語の「主人公」ではない。顧客こそが主人公であり、あなたは「ガイド」である。
```

- 脳は「生存」と「カロリー節約」を優先する。複雑すぎるメッセージは、脳が処理を拒否（無視）する。
- 混乱を排除し、顧客が自分の人生という物語において「どう進歩できるか」を語る。

---

## 1. 7つの要素 (SB7フレームワーク)

ストーリーを以下の7つの要素で構築する。

1. **主人公 (A Character)**: 顧客のこと。彼らが「何を求めているか」を明確にする。
2. **問題に直面する (With a Problem)**:
    - 外的な問題（例: 家が汚い）
    - 内的な問題（例: 片付けられない自分にイライラする）
    - 哲学的な問題（例: 誰しも心地よい家に住む権利がある）
3. **ガイドに出会う (And Meets a Guide)**:
    - 共感 (Empathy) を示し、
    - 権威 (Authority/実績) を証明する。
4. **計画を授ける (Who Gives Them a Plan)**:
    - 混乱を避け、簡単な3ステップ程度の「成功への道筋」を示す。
5. **行動を促す (And Calls Them to Action)**:
    - 直接的な呼びかけ（購入、予約、登録など）を明確にする。
6. **失敗を回避する (That Helps Them Avoid Failure)**:
    - 行動しなかった場合に、どのような「損失」や「悲劇」が待っているか。
7. **成功を収める (And Ends in a Success)**:
    - その製品によって、主人公の人生がどう変わるか（ビジョン）。

---

## 2. 良いメッセージの条件: 「グラント（うなり声）テスト」

原始人がメッセージを見たとき、以下に答えられるか？
1. あなたは何を売っているのか？
2. それは私の人生をどう良くするのか？
3. それを買うにはどうすればいいのか？

---

## 3. 実践のコツ

- **情報を削ぎ落とす**: 顧客に伝えるべきなのは「彼らの問題を解決するために役立つ情報」のみ。
- **内的問題を解決する**: 人は外的な問題を解決するために製品を買うが、購入の動機は「内的不満の解消」にある。
- **「ヒーロー」にならない**: 自社の歴史やスペックの自慢は、顧客（主人公）にとって「競合するヒーロー」に見え、遠ざけてしまう。

---

## 4. チェックリスト

### 文章作成・プレゼンの前に

```
[ ] 主語が「私たち」ではなく「あなた（顧客）」になっているか？
[ ] 顧客が抱えている「内的不満（イライラ、不安）」に言及しているか？
[ ] 自分が「導き手（ガイド）」として、共感と実績を示せているか？
[ ] 次に取るべき行動（ステップ）が、バカげているほどシンプルか？
[ ] 最後に「成功した未来の姿」を鮮明に描いているか？
```

## Claude に適用する場合のプロンプト冒頭

```
ストーリーブランド (SB7) フレームワークで、メッセージを構成してください。
1. 顧客を「主人公」に据え、彼らが求めている「進歩」を特定する
2. 顧客が直面している問題を「外的・内的・哲学的」な3層で定義する
3. 私（またはこの製品）が「ガイド」として、どのように共感と権威を示すか提案する
4. 顧客が迷わないための「3ステップの計画」と、明確な「行動喚起」を作成する
5. 「失敗の回避」と「成功のビジョン」を対比させて、強力なエンディングを描く
```

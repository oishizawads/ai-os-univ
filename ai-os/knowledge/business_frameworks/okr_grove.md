# OKR (Objectives and Key Results) — 目標管理フレームワーク

> 出典: アンディ・グローブ、ジョン・ドーア『Measure What Matters』
> 用途: 組織・個人の目標設定、優先順位の明確化、高速な実行

---

## 0. 根本原則

```
野心的な目標 (O) を掲げ、それを検証可能な数値 (KR) で計測する。
```

- **Objective (目標)**: 何を成し遂げたいか。定性的で、人を鼓舞し、野心的なもの。
- **Key Results (主要な結果)**: 目標達成をどう計るか。定量的で、具体的で、期限があり、挑戦的なもの。

---

## 1. OKR の特徴

| 特徴 | OKR | 従来のKPI/MBO |
|------|-----|--------------|
| **頻度** | 四半期ごと（高速） | 1年ごと |
| **透明性** | 全員に公開 | 上司と本人のみ |
| **野心度** | 60-70%達成で成功（ストレッチ） | 100%達成が前提 |
| **評価との連動** | 直接連動させない（挑戦を促すため） | 報酬・昇進に直結 |

---

## 2. OKR 設定のルール

### Objective (O)
- 達成したらワクワクするか？
- 具体的かつ行動につながるか？
- 数値を含まない（数値はKRに任せる）。

### Key Results (KR)
- 1つの O に対し、3〜5個程度。
- 「達成したか否か」が誰の目にも明らかな数値であること。
- 達成するのがかなり難しい（100%達成は稀）水準にする。

---

## 3. 運用のリズム

1. **チェックイン (Weekly)**: 進捗の確認、自信度の更新、障害の特定。
2. **中間レビュー**: 状況の変化に応じた KR の調整。
3. **スコアリング (Quarterly)**: 0.0 〜 1.0 で達成度を評価（0.6〜0.7 がベスト）。
4. **ふりかえり**: 次の四半期に向けての学習。

---

## 4. チェックリスト

### 目標設定の際に

```
[ ] その Objective は、あなたやチームをワクワクさせるか？
[ ] Key Results は、誰がどう見ても客観的に計測可能か？
[ ] 「100%達成が当たり前」の安全な目標になっていないか？
[ ] OKR の数は絞り込まれているか？（多すぎると集中力が分散する）
[ ] その目標を達成することで、北極星（究極の目的）に近づくか？
```

---

## Claude に適用する場合のプロンプト冒頭

```
OKRフレームワークを用いて、目標を構造化してください。
1. 挑戦的で、達成した時に大きな進歩を感じられる定性的な Objective (O) を1つ設定する
2. その達成を客観的に証明する、定量的で期限のある Key Results (KR) を3つ作成する
3. KRは「60-70%の達成がやっと」であるような、ストレッチした目標にする
4. 各 KR を達成するための具体的なアクション（タスク）をいくつか列挙する

```

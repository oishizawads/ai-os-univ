# 7つの習慣 — 人格主体・人生経営フレームワーク

> 出典: スティーブン・R・コヴィー『7つの習慣』
> 用途: 長期的な自己改善、人間関係の構築、人生の優先順位付け

---

## 0. 根本原則

```
インサイド・アウト（内から外へ）:
状況を変えたければ、まず自分の「パラダイム（ものの見方）」と「人格」を変える。
```

- **P/PCバランス**: 成果(P)と、成果を生み出す資産(PC)（自分自身や人間関係）のバランスを保つ。
- **依存から自立、そして相互協力へ**: 成熟の連続体を登る。

---

## 1. 私的成功（自立）

1. **第1の習慣：主体的である (Be Proactive)**
   - 刺激と反応の間に「選択の自由」を持つ。
   - 「影響の輪」に集中し、自分がコントロールできることから変えていく。
2. **第2の習慣：終わりを思い描くことから始める (Begin with the End in Mind)**
   - 自分の人生の「ミッション・ステートメント（信条）」を持つ。
   - すべての行動を、最終的なゴール（葬儀でどう語られたいか）から逆算する。
3. **第3の習慣：最優先事項を優先する (Put First Things First)**
   - 第2領域（緊急ではないが重要）に時間を割く。
   - スケジュールに優先順位をつけるのではなく、優先事項をスケジュールに組み込む。

---

## 2. 公的成功（相互協力）

4. **第4の習慣：Win-Winを考える (Think Win-Win)**
   - 自分も勝ち、相手も勝つ「第3の案」を常に探す。それが無理なら「No Deal（取引しない）」。
5. **第5の習慣：まず理解に徹し、そして理解される (Seek First to Understand, Then to be Understood)**
   - 「共感による傾聴」を行い、相手の心理的空気を満たす。
   - 処方箋を出す前に、徹底的に診断する。
6. **第6の習慣：シナジーを創り出す (Synergize)**
   - 違いを尊重する。1+1を3にも10にもする創造的な協力を目指す。

---

## 3. 再新再生（磨き直し）

7. **第7の習慣：刃を研ぐ (Sharpen the Saw)**
   - 4つの側面（肉体、精神、知性、社会・情緒）を定期的にメンテナンスし、PC（資産）を高める。

---

## 4. 実践：時間管理マトリクス（第2領域への集中）

| | 緊急 | 緊急ではない |
|---|---|---|
| **重要** | 第1領域: 危機・期限のある仕事 | **第2領域: 準備・計画・自己啓発・人間関係** |
| **重要ではない** | 第3領域: 無意味な接待・多くの会議 | 第4領域: 暇つぶし・過度の娯楽 |

---

## 5. チェックリスト

### 自分の行動を振り返る

```
[ ] 今、自分は「影響の輪（変えられること）」に集中しているか？
[ ] 今日の活動は、自分の「ミッション」に沿っているか？
[ ] 「緊急ではないが重要なこと（第2領域）」に、今日15分でも割いたか？
[ ] 相手の話を聞くとき、反論を準備せずに「理解しよう」としているか？
[ ] 「刃を研ぐ」活動（読書、運動、瞑想など）を今週予定しているか？
```

## Claude に適用する場合のプロンプト冒頭

```

1. 現在の悩みを「影響の輪」と「関心の輪」に分け、私が直接コントロールできる行動を特定する
2. 提案が、私の長期的な「P/PCバランス（成果と資産の維持）」にどう寄与するか示す
3. 提示されたタスクを時間管理マトリクスの4つの領域に分類し、特に「第2領域（重要だが緊急でない）」を強調する
4. 人間関係が関わる場合、どのように Win-Win を目指し、まず相手を理解すべきか具体策を練る
```

# ジョブ理論 (Jobs to be Done) — 顧客理解フレームワーク

> 出典: クレイトン・クリステンセン『ジョブ理論』
> 用途: 本質的な顧客ニーズの特定、新機能・新製品の企画、競合の再定義

---

## 0. 根本原則

```
顧客はある「ジョブ（片づけたい用事）」をこなすために、製品を「雇用」する。
```

- 顧客の属性（年齢、性別、居住地）ではなく、**「その人がどのような状況で、何を成し遂げたいか」**という文脈に注目する。
- 顧客は製品そのものが欲しいのではなく、その製品によって得られる「進歩（Progress）」を求めている。

---

## 1. ジョブを定義する3つの側面

ジョブは単なる機能的な欲求ではなく、多面的なものとして捉える。

| 側面 | 内容 | 例（ミルクシェイクの購入） |
|------|------|---------------------------|
| **機能的ジョブ** | 実現したい具体的なタスク | 運転中に退屈を凌ぎたい、腹持ちを良くしたい |
| **情緒的ジョブ** | 本人がどう感じたいか | 忙しい朝に少しだけ自分を甘やかしたい |
| **社会的ジョブ** | 他者からどう見られたいか | （子供の前で）良い親だと思われたい |

---

## 2. ジョブ特定の問い（ジョブ・ステートメント）

ジョブを特定する際は、以下の構造で記述する。

```
[状況] のときに、
[解決したい問題/達成したいこと] をしたい。
なぜなら [理想の状態] になりたいからだ。
```

**例**:
- 「朝の通勤中（状況）に、退屈を凌ぎつつ小腹を満たしたい（達成したいこと）。なぜなら、会社に着くまでの時間を有意義に感じたいからだ（理想）。」

---

## 3. 競合の再定義

ジョブの視点に立つと、競合は「同じカテゴリの製品」だけではなくなる。
- **例**: ミルクシェイクの競合は、ドーナツやバナナ（小腹を満たす）、あるいはオーディオブック（退屈を凌ぐ）かもしれない。

### 雇用と解雇 (Hire & Fire)
新しい製品を「雇用」するということは、今まで使っていた何かを「解雇」することを意味する。
- **阻害要因**: 既存の習慣（固執）、新しいものへの不安。
- **促進要因**: 現状への強い不満、新製品への強い魅力。

---

## 4. チェックリスト

### 企画・分析の際に

```
[ ] 顧客がこの製品を「雇用」する具体的なシーン（状況）は何か？
[ ] 顧客はこの製品を使って、どのような「進歩」を遂げようとしているか？
[ ] 機能的側面だけでなく、情緒的・社会的なジョブは考慮されているか？
[ ] 顧客がこの製品を雇うために、「解雇」しなければならないものは何か？
[ ] 既存の習慣という「強力な競合」をどう乗り越えるか？
```

---

## Claude に適用する場合のプロンプト冒頭

```
ジョブ理論の視点で分析してください。
1. 私の要望の背後にある「片づけたい用事（ジョブ）」を、機能的・情緒的・社会的な側面から特定する
2. そのジョブが発生する具体的な「状況（文脈）」を想定する
3. 私が現在「雇用」している代替手段（習慣や既存ツール）を検討する
4. それらを「解雇」してでも、あなたの提案を「雇用」したくなるような、本質的な価値提案を行う
---
[本題をここに記述]
```

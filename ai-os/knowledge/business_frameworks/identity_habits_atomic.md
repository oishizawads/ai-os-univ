# ジェームズ・クリアー式 習慣化 — 行動変容フレームワーク

> 出典: ジェームズ・クリアー『複利で伸びる 1つの習慣（Atomic Habits）』
> 用途: 良い習慣の構築、悪い習慣の打破、自己規律の仕組み化

---

## 0. 根本原則

```
習慣は「自己改善の複利」である。毎日1%の改善は、1年後には37倍の成果になる。
```

- **目標ではなく「システム」に集中する**: 目標は結果を設定するが、システムはその結果に至るプロセスを構築する。
- **アイデンティティ・ベースの習慣**: 「何を達成したいか」ではなく「どのような自分になりたいか」から出発する。

---

## 1. 良い習慣を作る「4つのステップ」

| ステップ | 法則 | 具体的な手法 |
|---------|-----|-------------|
| **1. きっかけ (Cue)** | はっきりさせる | **習慣の積み重ね**: [現在の習慣] の後、[新しい習慣] をする。 |
| **2. 欲求 (Craving)** | 魅力的にする | **誘惑の抱き合わせ**: [必要な習慣] と [やりたい習慣] をセットにする。 |
| **3. 反応 (Response)** | 易しくする | **2分間ルール**: どんな新しい習慣も、まずは2分以内でできることから始める。 |
| **4. 報酬 (Reward)** | 満足感を与える | **習慣トラッカー**: 実行したことを視覚的に記録し、成功を感じる。 |

---

## 2. 悪い習慣を断つ「4つのステップ（逆）」

1. **きっかけを「見えないようにする」**: 誘惑の元となる環境を物理的に排除する。
2. **欲求を「つまらなくする」**: その習慣のデメリットを再定義し、魅力を失わせる。
3. **反応を「難しくする」**: 手間（摩擦）を増やす。
4. **報酬を「不快にする」**: 誰かに監視を頼むなど、失敗した時のコストを作る。

---

## 3. 実践のコツ: 環境設計 (Design for Flow)

習慣を「意志の力」に頼らない。
- **摩擦を減らす**: ジムに行きたいなら、前夜にウェアを玄関に置いておく。
- **摩擦を増やす**: スマホを使いすぎるなら、別の部屋に置く。
- **環境は最強のきっかけ**: 人間の行動は「何ができるか」ではなく「何が目に見えるか」に左右される。

---

## 4. チェックリスト

### 新しい習慣を始めるとき

```
[ ] その習慣は、自分が「なりたいアイデンティティ」と一致しているか？
[ ] 「いつ、どこで、何をするか（実行意図）」が明確か？
[ ] その習慣を始めるためのステップは「2分以内」で終わるか？
[ ] 良い習慣を行うための「環境（物理的きっかけ）」は整っているか？
[ ] 悪い習慣を行うための「手間（摩擦）」を最大化できているか？
```

4. 私の周囲の環境（物理的配置）をどう変えれば、意志の力に頼らずに実行できるか提案する

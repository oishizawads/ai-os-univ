# AI パターン集

AI 活用で成功した実装パターンを記録・再利用するためのディレクトリ。

## 使い方

1. 新しいパターンを記録する際は `ai-os/templates/pattern_template.md` をコピー
2. ファイル名は `カテゴリ_パターン名.md` とする
3. 使用履歴を追記し、定期的に改善

## カテゴリ

- `auth` - 認証・認可
- `db` - データベース
- `api` - API 設計
- `ui` - UI/UX
- `security` - セキュリティ
- `performance` - パフォーマンス
- `testing` - テスト
- `deployment` - デプロイ

## ガイドライン

- パターンは具体的で再現可能であること
- 制約条件と落とし穴を必ず記録
- 使用履歴で効果測定

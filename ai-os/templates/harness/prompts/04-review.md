# プロンプト: コードレビュー

PR番号を差し替えて Claude Code に貼り付ける。

---

```
PR #<pr#> をレビューしてください。

## レビュー観点（4カテゴリ）

### 1. 仕様整合
- Issue の受け入れ条件を全て満たしているか
- 設計書（Issue コメント）との乖離はないか
- 考慮漏れのエッジケースはないか

### 2. セキュリティ
- 認証・認可の漏れ
- 入力バリデーション
- secrets の露出
- SQL インジェクション / XSS

### 3. コード品質
- 責務分離・単一責任
- 不要な複雑化・過剰抽象化
- エラーハンドリングの適切さ
- デッドコード・デバッグコード残留

### 4. テスト
- テスト観点の網羅（正常系・異常系・境界値）
- テストの信頼性（flaky になりそうか）

## 出力形式

各カテゴリで問題を列挙し、最後に総合判定を出す。

### 総合判定
- ✅ Approve: 問題なし、マージ可
- ⚠️ Comment: 軽微な指摘あり、対応は任意
- 🔄 Changes Requested: 修正後に再レビュー必要
```

---

## 使い方

1. 上のプロンプトをコピー
2. `<pr#>` を実際の番号に置換
3. Claude Code に貼り付けて実行
4. Approve なら GitHub で Approve → マージ
5. Changes Requested なら Codex に差し戻し

# プロンプト: 詳細設計・タスク分割

Issue番号を差し替えて Claude Code に貼り付ける。

---

```
Issue #<issue#> の詳細設計と実装タスク分割を行ってください。

以下を出力してください:

## 1. 実装方針
（どのように実装するか。アプローチの選択肢と採用理由）

## 2. 影響範囲
（変更対象のファイル・モジュール・API・DB）

## 3. PR分割計画
（1PR = 1実装単位で分割。依存順に並べる）

| # | PR内容 | 依存 | 見積時間 |
|---|-------|------|---------|
| 1 | ...   | なし | 1h      |
| 2 | ...   | PR1  | 2h      |

## 4. 子Issue一覧（そのまま作成できる形式で）

### 子Issue 1
**タイトル**: 
**本文**:
（実装仕様・影響範囲・テスト観点を記入）

### 子Issue 2
...
```

---

## 使い方

1. 上のプロンプトをコピー
2. `<issue#>` を実際の番号に置換
3. Claude Code に貼り付けて実行
4. 出力を確認・承認
5. 子Issueをそれぞれ作成（GitHubのSub-issues機能 or 手動）
6. 各子Issueに `status:ready`, `agent:codex` を付与

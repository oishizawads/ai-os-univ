# プロンプト: 実装委譲（Codex）

Issue番号を差し替えて Codex に投げる。

---

```
Issue #<issue#> を実装してください。

## 指示

1. Issue 本文の「実装仕様」「影響範囲」「テスト観点」を読む
2. 実装する
3. テストを作成する（テスト観点を全てカバー）
4. PR を作成する

## PR 作成ルール

- タイトル: `feat: <実装内容の要約> (closes #<issue#>)`
- 本文: PRテンプレート（`.github/PULL_REQUEST_TEMPLATE.md`）に沿って記入
- ベースブランチ: main（または指示があれば feature ブランチ）

## 完了条件

- [ ] Issue の受け入れ条件を全て満たしている
- [ ] テストが通っている
- [ ] PR が作成されている
```

---

## 使い方

```
/codex:rescue <上のプロンプトを貼り付け>
```

または Claude Code から:

```
Codex に委譲してください: （上のプロンプト）
```

# プロンプト: 要件定義壁打ち

Issue番号を差し替えて Claude Code に貼り付ける。

---

```
Issue #<issue#> の要件定義を行ってください。

以下の手順で進めてください:

1. Issueの内容（背景・ゴール・受け入れ条件・制約）を読む
2. 実装に入る前に確認が必要な不明点・曖昧点をリストアップする
3. 不明点を箇条書きでIssueコメントとして投稿する形式で出力する

出力形式:
## 要件確認

### 確認事項
- [ ] （不明点1）
- [ ] （不明点2）

### 現時点の理解
（Issueの内容を自分の言葉でまとめる）

### リスク・懸念点
（技術的リスク、スコープ外になりそうな箇所など）
```

---

## 使い方

1. 上のプロンプトをコピー
2. `<issue#>` を実際の番号に置換
3. Claude Code に貼り付けて実行
4. 出力をIssueコメントにコピーして投稿
5. 人間が回答→全て解消したら「要件確定」とコメント
